## Tier key

- **VERIFIED** — I opened the primary artifact and can quote it. Capture on disk.
- **VERIFIED-BY-WORKER** — a named worker fetched the primary in its transcript, but no disk capture. Weaker: reader cannot independently re-check.
- **SECONDHAND** — news, relay, aggregator. Interview statements about living persons are SECONDHAND unless the recording itself is captured.
- **UNCONFIRMED** — could not be established; reason stated. Negative coverage ≠ nonexistence.
